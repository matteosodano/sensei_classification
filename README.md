# Object Classification and Multi-Camera Evaluation

This repository contains the code developed for the object classification task, including model training, evaluation, and multi-camera analysis.

## Repository status and reproducibility

The original implementation was developed and executed in Google Colab, where GPU access was available. The Colab notebook included in this repository is the implementation that was actually used to train and evaluate the models.

For the purpose of making the project easier to read and navigate, the code has also been reorganized into separate Python files with a cleaner structure.

However, there is an important limitation to be explicit about:

*The reorganized .py files have not been executed end-to-end after being extracted from the Colab notebook.*

At the moment, I do not have access to a GPU, as I am currently between positions. Consequently, I was unable to rerun the cleaned-up code to verify it after restructuring it.

The standalone Python files should therefore be considered illustrative and organizational versions of the code, intended to make the implementation easier to understand, reuse, and extend. The Google Colab notebook is the reference implementation that was actually executed and used to generate the models and evaluation results.

I have intentionally included the original notebook despite its less polished organization so that the executed implementation and the cleaned-up code can be compared directly.
